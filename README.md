POLITIQUE DE CONFIDENTIALITÉ — InazumaBotV2

Dernière mise à jour : [date du jour]

1. QUELLES DONNÉES SONT COLLECTÉES
InazumaBotV2 collecte et stocke les données suivantes, liées à ton identifiant Discord :
- Ton progrès de jeu (cartes possédées, monnaies virtuelles, niveau, statistiques)
- Ton historique de matchs joués sur le bot
- Ton appartenance à un club, ton rôle et ton serveur d'origine
- Les échanges et transactions effectués via le bot

Le bot ne collecte JAMAIS ton mot de passe Discord, tes messages privés, ou le contenu de tes 
messages sur les serveurs (aucun accès au contenu des messages n'est utilisé).

2. POURQUOI CES DONNÉES SONT COLLECTÉES
Ces données servent uniquement à faire fonctionner les fonctionnalités de jeu du bot : 
sauvegarder ta progression, afficher les classements, permettre les échanges entre joueurs, et 
gérer les clubs.

3. OÙ ET COMMENT LES DONNÉES SONT STOCKÉES
Les données sont stockées dans une base de données privée, hébergée sur un serveur dédié au 
bot. Elles ne sont jamais vendues, partagées avec des tiers, ni utilisées à des fins 
publicitaires.

4. DURÉE DE CONSERVATION
Les données sont conservées tant que ton compte reste actif sur le bot. Tu peux demander leur 
suppression à tout moment (voir section 5).

directement sur Discord : 588468904431583232 @costy91 . Tes données seront supprimées définitivement
